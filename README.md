# Voltix Mobile

**Your destination for quality mobile accessories.**

Voltix Mobile is a responsive e-commerce website developed to showcase and sell mobile accessories, including phone chargers, AirPods, phone cases, and other essential mobile products.

## About the Project

Voltix Mobile aims to provide customers with a simple and convenient online shopping experience. The website features a clean interface, product browsing, shopping cart functionality, and an order management demonstration.

## Features

- **Homepage:** Introduces the brand and showcases featured products.
- **Product Catalogue:** Displays available mobile accessories.
- **Shopping Cart:** Allows customers to add products and view selected items.
- **Cart Counter:** Updates to reflect the number of items added.
- **Checkout:** Provides a checkout process for customer orders.
- **Order Management:** Displays submitted orders through an administrative page.
- **Contact Page:** Provides customers with a way to get in touch.
- **Responsive Design:** Supports desktop, tablet, and mobile screen sizes.
- **Interactive Elements:** Includes JavaScript functionality, animations, transitions, and dynamic DOM manipulation.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling, layouts, animations, and responsive design.
- JavaScript – Interactive functionality and dynamic content.
- LocalStorage – Stores cart information and demonstration orders locally.

## Running the Project

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using a local development server, such as Live Server.
4. Browse the website and test its functionality.

## Important Notes

This project is currently a front-end e-commerce demonstration.

- Cart and order information is stored using browser LocalStorage.
- Orders are not transmitted to a real backend server.
- No real payment processing is currently implemented.
- Stored information is specific to the browser and device being used.
